Був створений Flask-застосунок для магазину електроніки (наявні дві
пов'язані таблиці categories та products) з можливістю переглядати
список об'єктів / один об'єкт. Також наявне створення, редагування,
видалення записів через форми

Додатково був створений тригер trg_products_price_log, який при кожному
оновленні ціни товару викликає log_price_change() для запису в таблицю
price_history (таблиця price_history відображається при перегляді
конкретного об'єкта)

Також була створена збережена функція update_product_price(), яка
оновлює ціну товару за його ID. Вона викликається із застосунку при
редагуванні товару, а оновлення ціни, у свою чергу, запускає тригер
trg_products_price_log

Інструкції для запуску

1. У pgAdmin 4 створити базу даних tech_shop

2. У Query Tool виконати код із файлу schema.sql

3. Відкрити термінал у папці проєкту та встановити Flask,
   psycopg2-binary: pip install Flask psycopg2-binary

4. Ввести в main.py дані для підключення:

       DB = dict(host="localhost", port=5432, dbname="tech_shop",
       user="postgres", password="пароль")

5. Запустити main.py та перейти за посиланням в терміналі
